---

## 1. 文档目的与适用范围

- **目的**：规定哪些数据经客户端处理后**允许写入 PostgreSQL**、以何种粒度展示，与立项书 **§4.2「绑定客户端执行」**、**第 6 节安全**一致。  
- **适用范围**：客户端 Playwright / 接口监听 / Excel 合并产出、并**上报云端**的结构化字段；**未在本白名单列出且未走完评审的字段，默认不得上云**。  
- **关联数据字典**：**`数据字典-员工账号.md`**、**`数据字典-视频.md`**、**`数据字典-线索.md`**、**`数据字典-任务与设备.md`**（任务元数据等非业务 PII 部分）。

---

## 2. 分级定义（示意，评审后可调整标签名）

| 级别 | 代号 | 含义 | 上云策略（示意） |
|------|------|------|------------------|
| L0 | `public` | 无个人指向的统计、枚举码、业务主键 | 可直接存储 |
| L1 | `low` | 间接识别风险低（如粗粒度地区码、意向等级码） | 可存；展示按 RBAC |

---

## 3. 工作流程（与 Playwright 对接）

1. **研发**：用 Playwright（含 **Trace / 网络监听**）在绑定客户端上跑通页面/API，记录 **JSON 路径 / DOM 锚点 / 响应 URL 模式** → 填入下表 **「解析来源（待 Playwright 定稿）」** 列。仓库内已提供本机探测脚本：**`tools/playwright-field-probe/`**（见该目录 **`README.md`**：`npm run login` 保存会话 → `npm run probe` 导出 **`.out/captured-json.ndjson`** 样本）。  
2. **产品 / 安全**：按 §2 为每个目标列定 **`level`** 与 **`transform`**（如：哈希、截断前 N 字、仅存省）。  
3. **实现**：客户端 **Runner 出口闸门** —— 仅允许上报白名单内字段；**版本化**本表（见 §6）。  
4. **变更**：新增字段须走 **PR + 安全评审** 并递增白名单文档版本。
